# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com)
and versions follow [Semantic Versioning](https://semver.org). One release per sprint; see CONTRIBUTING.md.

## [Unreleased]

### Added
- Repository with a feature-branch workflow (PRs into `main`, one tag per sprint), CI, Git LFS and an empty visionOS 27 app skeleton. The Xcode project is
  committed and uses synced folders (no XcodeGen).

- Untangle the Dragon (AR126-100): floating island with a dragon circling its tree, untangling puzzle, farewell
  flight; one island window, one dragon panel, one immersive space; visionOS 26.5 deployment target.
- The tree's fruit: apples with a Metal spiral-cut opening and worms guarding the artifact that soothes the dragon,
  and a bonus pomegranate (from Isadora's AppleSpiral prototype).

### Changed
- All code comments, scripts and docs are in English.
- Renamed the project from the placeholder SkyAndPlanets to Macrowavers (app, targets, bundle ID com.arte1.macrowavers).
